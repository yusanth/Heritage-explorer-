📚 Indian Knowledge Systems connection

Indian Knowledge Systems (IKS) include knowledge and practices developed and transmitted across generations in areas such as architecture, arts, philosophy, ecology and community life.

This project connects IKS with information technology by organizing heritage facts in a searchable digital collection and using interest-based matching to guide exploration. It supports awareness and learning; it does not replace scholarly sources or local community knowledge.

About this project

Project: Heritage Explorer Using AI

Course: TY BSc IT — Individual IKS Project

Method: Client-side JavaScript, structured heritage knowledge base, keyword search, tag-based recommendation and rule-based question matching.

Limitation: The assistant answers from the included knowledge base. It is not connected to a live generative AI model or external API.
